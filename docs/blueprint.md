# **App Name**: Recovery Tracker

## Core Features:

- Main Abstinence Timer: Displays the elapsed time since the user started abstaining from a chosen habit in a prominent, easy-to-read square window.
- Habit Configuration: Allows the user to define and name the specific habit they are tracking. Includes functionality to start or reset the abstinence timer for the chosen habit.
- Offline Persistence: Stores the habit information and current timer progress locally on the device, ensuring the app functions completely without an internet connection.
- Settings Access: A button on the top-right of the main screen to open an empty, right-aligned pop-up settings panel.
- Account Management: A button on the top-left of the main screen to open an empty, left-aligned pop-up account panel.
- Dynamic Pop-up Navigation: Implements pop-up windows for settings and account sections, featuring a clear 'back' button within each to return to the main tracker view.

## Style Guidelines:

- Primary color: A balanced and stable mid-tone blue (#396EAA). This shade embodies tranquility and commitment, providing a grounding feel for tracking progress.
- Background color: A very light, almost white, blue-gray (#F2F6F9). This light, airy backdrop ensures focus and clarity on the main content without distraction.
- Accent color: A vibrant yet serene violet (#7D57E6). This color symbolizes transformation and strength, providing a contrasting highlight for interactive elements and key indicators.
- Headline and body text font: 'Inter', a modern sans-serif. Chosen for its exceptional readability, clean lines, and neutral aesthetic, which perfectly supports clear information delivery and symmetry. 
- Layout emphasizes symmetry and grid principles, ensuring all elements are proportioned to fit the screen without requiring scrolling, promoting a streamlined and focused user experience.
- Simple, clean line icons for navigation elements (settings, account, back button) to maintain clarity and match the app's minimalist aesthetic.
- Subtle, smooth slide animations for pop-up panels entering from the sides and for button presses, providing intuitive visual feedback without being overly distracting.
